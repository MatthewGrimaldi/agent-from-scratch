\# AI Agent Test Project (Simple Stock Price Calculator)



\### Purpose:

I made this project to educate myself on how AI agents work and how they can use tools to break down tasks into simpler parts. No agent frameworks were used, this was all built in raw python so that I may learn the mechanisms behind agentic AI.



The program acts as a basic comparison tool for stock prices stored in the prices.csv file.



\### Features:

* Multi-step tool use
* A safe calculator (doesn't use Python's default eval function to avoid unauthorized code executions through CSV manipulation)
* Sandboxed file reading
* Error recovery
* Turn limits with graceful wrap-up
* Token usage tracking



\### How to run it:

* Clone
* Create a venv
* Install requirements
* Add a new .env with your own key
